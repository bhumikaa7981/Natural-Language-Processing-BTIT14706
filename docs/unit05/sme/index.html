Rule #1

There are only 3 moves. That's it.

Every single edit — no matter how fancy the words are — boils down to one of these three tiny moves.

➕

Insert

cat → cart

Sneak in a missing letter. cat → cart: insert "r".

✂️

Delete

cart → cat

Kick out a letter that shouldn't be there. cart → cat: delete "r".

🔁

Substitute

caot

Swap one letter for another. cat → cot: substitute "a" → "o".

Real talk

Why does your phone think "graffe" = "giraffe"?

Your phone doesn't know spelling. It just quietly counts edits against every word it knows, and picks whoever needs the fewest.

The main event

Watch a Dynamic Programming table fill in — one click at a time

Every cell only ever looks at 3 neighbours (the one above, the one to the left, and the one diagonally above-left) and picks whichever is cheapest. Click Next Cell, hit Play, or tap the glowing cell yourself.

🤓 Show me the actual formula (optional, nerds only)
D(i,0) = i    D(0,j) = j
D(i,j) = min( D(i-1,j)+1,   D(i,j-1)+1,   D(i-1,j-1) + cost )
cost = 0 if letters match, else 1 (unit-cost) or 2 (Levenshtein)
