Rule #1

There are only 3 moves. That's it.

Every single edit — no matter how fancy the words are — boils down to one of these three tiny moves.

➕

Insert

cat → cart

Sneak in a missing letter. cat → cart: insert "r".

✂️

Delete

cart → cat

Kick out a letter that shouldn't be there. cart → cat: delete "r".

🔁

Substitute

caot

Swap one letter for another. cat → cot: substitute "a" → "o".

Real talk

Why does your phone think "graffe" = "giraffe"?

Your phone doesn't know spelling. It just quietly counts edits against every word it knows, and picks whoever needs the fewest.

🧠 Simple Rule — how every cell gets its number

Before touching any formula, just answer one question: are the two current letters the same, or different?

✅ SAME letters

Example: comparing "I" vs "I" → they match.

D(i,j) = D(i-1,j-1) + 0

👉 Just copy the diagonal number down. No extra cost — it's a free move.

❌ DIFFERENT letters

Now you compare 3 choices and take the cheapest one.

D(i,j) = MIN( ↖diag + sub,  ↑top + 1,  ←left + 1 )
↖ Diagonal = Substitute ↑ Top = Delete (+1) ← Left = Insert (+1)
OperationUnit-costLevenshtein
Same character (↖)+0+0
Substitute (↖)+1+2
Delete (↑)+1+1
Insert (←)+1+1

The DP logic never changes — only the substitution price changes between the two versions. That single number is the only difference between the Unit-cost and Levenshtein toggle in every example below. Open any tab, switch the toggle, and click a cell — the explainer under the table walks through this exact Same/Different rule for that cell, live.

🤓 Show me the actual formula (optional, nerds only)
D(i,0) = i    D(0,j) = j
D(i,j) = min( D(i-1,j)+1,   D(i,j-1)+1,   D(i-1,j-1) + cost )
cost = 0 if letters match, else 1 for Unit-cost editing, or 2 for classic Levenshtein distance (a substitution is treated as a delete + insert bundled together).
