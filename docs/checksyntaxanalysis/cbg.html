Plain CFG's blind spot

Same shape, same green light — every time.

A context-free rule only checks the outline of a sentence. It can't see inside the words.

✓ Allowed (correctly)
The dog runs.

Agrees — but only by accident of word choice, not because any rule checked it.

✗ Also allowed (wrongly)
The dogs runs.

S → NP VP matches this shape too. The grammar has no way to say "no."

The one question

Can these two puzzle pieces snap together?

That's it. That's unification — before it ever gets a fancy name. Agree → combine. Clash → stop right there. You already use this logic five times a day. Here's proof:

🧩
Jigsaw puzzle
Two pieces only lock together if their bumps and notches actually match.
✓ bump=notch snaps  |  ✗ bump=bump jams
🔌
Charging cable
Type-C plug meets Type-C port: instant power. Type-C meets micro-USB: absolutely nothing.
✓ C=C charges  |  ✗ C=micro nope
💘
Dating app
It's a match only if both sides agree on city, vibe, and weekend plans — one mismatch, no match.
✓ city=city match  |  ✗ city≠city pass
☕
Chai order
"Large, in a kulhad" — but kulhads only come in one size. Order rejected, no chai for you.
✓ size=regular served  |  ✗ size=large denied
💬
Group plan
You say 6pm, your friend says 6pm — plan confirmed. You say 6, they say 8 — plan's off.
✓ 6=6 confirmed  |  ✗ 6≠8 cancelled
🧦
Matching socks
Two socks make a pair only if colour and size line up — one odd sock and the pair fails.
✓ navy=navy pair  |  ✗ navy≠grey odd one out

Bonus round

Some info is vaguer than other info — on purpose.

number = ?
(I know there's a number feature —
just not which value yet)
number =
singular

"number = ?" is happy to cover any specific value later handed to it. That's called subsumption — the general description "covers," or subsumes, the specific one. Never the other way round.

Real-world version: a college notice says "submit your ID" (general). Aadhar, PAN, or student card — all satisfy it (specific). The notice doesn't care which, as long as one shows up.

Bonus round 2

Some connections stretch across the whole sentence.

A word up front can be "waiting to be used" much further down the line.

Which books did you say (that) she read ___ ?

"Which books" is the object of "read" — even though it sits at the very front. A gap feature gets threaded (unified) through every phrase in between until it finally finds its match, like a relay baton.
