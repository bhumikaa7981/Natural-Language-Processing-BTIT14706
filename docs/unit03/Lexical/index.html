Finite State Transducers: The Basic Idea

One machine, two tapes, and a set of tiny rules — read the underlying form on top, write the surface form on the bottom, one symbol at a time.

Upper tape (underlying) → FST → Lower tape (surface)
  1. Two tapes, not one. An FST reads an underlying string and writes a surface string at the same time, moving through labelled states.
  2. Arc labels are pairs. Every step is upper : lower — g:g copies a letter, ^:ε deletes a boundary, ε:e inserts a letter out of nowhere.
  3. Fully reversible. Run it one way for analysis (surface → lemma), run it backwards for generation (lemma → surface). Same network, same rules.
  4. Why it won. It's fast, small, and this built-in reversibility is exactly what parsing and generation both need.
